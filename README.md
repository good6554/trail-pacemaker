# 🏔️ Trail Pacemaker

GPX 파일 기반 트레일 러닝 페이싱 전략 웹앱 (Streamlit).

## Live Demo
배포 후 여기에 링크: `https://<your-app>.streamlit.app`

## 로컬 실행
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## 기능
- 러너 신체 정보 & 목표 시간 입력
- 체크포인트(CP) 관리 (추가/수정/삭제)
- GPX 업로드 → 구간별 페이스·전략 자동 산출
- 고도 프로파일 시각화
- 결과 텍스트 다운로드
